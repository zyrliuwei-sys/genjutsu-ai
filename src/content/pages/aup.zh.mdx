# AIGC 使用规范（AUP）

_最后更新：2026-10-09_

本 AIGC 使用规范（AUP）适用于您使用 Genjutsu AI 创建、上传、保存或分享 AI 生成视频的行为。本规范是对[服务条款](/terms-of-service)的补充。如果本规范与强制适用的法律要求不一致，以法律要求为准。

## 内容标准

您必须以负责任的方式使用 Genjutsu AI，并且只能用于合法且获得授权的用途。具体包括：

- 仅使用您有权使用或已经获得授权的提示词、参考图片、标识、角色及其他素材。
- 上传可识别人物的肖像，或生成描绘该人物的内容前，应取得真实、充分的本人同意。
- 不得利用生成内容欺骗、诈骗、骚扰、威胁、剥削他人，或使他人面临现实风险。
- 尊重隐私权、知识产权、姓名肖像权、商标权及其他合法权利。
- 不得通过混淆提示词、切换账户或其他方式规避安全控制、过滤规则、账户限制或内容审核。
- 分享可能被误认为真实记录或真实言论的生成内容时，应明确标注其为 AI 生成内容。

## 内容标准与禁止类别

以下六类内容禁止生成。根据违规的严重程度和具体情况，平台可能在生成前拦截提示词或结果、删除内容、限制功能、暂停账户或终止账户。

### 1. 色情 / NSFW 内容

禁止生成色情内容、露骨性行为、性化裸露、恋物内容、性交易或性服务招揽，以及未经同意的私密影像。即使涉及成年人，未取得本人同意的性内容也禁止生成。不得未经他人许可上传其私密照片。

### 2. 暴力 / 血腥内容

禁止生成血腥暴力、肢解或严重伤害的逼真画面、性暴力、赞美现实暴力的内容，或实质性帮助实施暴力违法行为的内容。威胁他人以及指导实施人身伤害的内容同样禁止。

### 3. 仇恨言论

禁止生成基于种族、民族、国籍、宗教、残障、性别、性取向、性别认同或其他类似受保护特征，对个人或群体进行攻击、非人化、赞美针对性暴力或号召歧视的内容。

### 4. 儿童不安全内容（CSAM）

平台对 CSAM 以及任何涉及未成年人的性化内容零容忍。禁止生成未成年人性剥削、诱骗、性化裸露、性行为，或将未成年人置于性化情境中的内容。不得利用 Genjutsu AI 促进儿童剥削、贩运或虐待。对于疑似 CSAM 或迫在眉睫的儿童安全风险，平台可能在法律要求或允许的范围内保存相关信息并向适当的执法或保护机构报告。

### 5. 深度伪造 / 冒充他人

禁止未经真实人物授权制作具有欺骗性的深度伪造或冒充内容，尤其是用于诈骗、勒索、骚扰、政治欺骗、金融活动或未经同意的色情内容。不得让真实人物看起来说过或做过其没有说过或做过的事情，并以误导他人为目的传播。获得授权且进行适当披露的合理变换可能允许，但您仍需负责取得同意并进行披露。

### 6. 侵犯版权 / 商标

禁止在未经授权的情况下复制受版权保护的作品、制作仿冒商品或误导性品牌素材，以侵犯权利的方式复制受保护角色或标识，或滥用他人的商标。您负责取得必要的许可，并确认提示词、上传素材和生成结果可以依法使用。

## 用户举报渠道

如果您发现疑似违反本 AUP 的内容，可以发送邮件至 [support@genjutsu-ai.org](mailto:support@genjutsu-ai.org) 举报。已登录用户也可以通过[提交支持工单](/settings/tickets)进行举报。

举报时请尽可能提供：

- 涉及的页面 URL、任务 ID 或账户信息。
- 疑似违规的具体描述和对应的政策类别。
- 截图，或在安全且合法的前提下提供相关提示词 / 结果。
- 是否存在即时安全风险、被冒充人物、权利人或受影响的未成年人。

请勿通过邮件或上传方式发送 CSAM。如果举报涉及生命危险、即将发生的人身伤害或儿童正处于紧急危险，请先联系当地急救服务或相关儿童保护机构，并在安全的情况下再通知平台。

## 平台内容审核机制

Genjutsu AI 采用基于风险的内容审核流程，可能包括：

1. **生成前检查：**每条自由文本提示词都会在发送给图片或视频服务商前，通过 Waffo Pancake Prompt Screening API 进行扫描。只有返回 `allow` 才会启动任务；返回 `review` 或 `block` 时，会在扣除积分前停止生成。Waffo 说明该扫描为无状态处理，被拦截或需要复核的提示词不会发送给所选模型服务商。相关上传素材还可能经过自动分类器、规则检查和模型服务商安全系统的筛查。
2. **生成后检查：**当自动系统标记风险、用户举报内容，或平台需要调查滥用、法律主张和安全事件时，平台可能审核生成媒体及相关元数据。
3. **举报分级：**涉及 CSAM、可信的人身威胁、未经同意的私密影像、针对性骚扰和持续性诈骗的举报会被优先处理。调查期间，平台可能临时限制相关内容或账户的访问。
4. **处理措施：**根据调查结论，平台可能拒绝生成、删除内容或关闭访问、限制账户功能、暂停或终止账户、取消相关任务，并配合权利人及执法机构依法提出的请求。
5. **重复违规与申诉：**重复或故意违规可能导致永久性账户处置。如果您认为处理决定有误，可以回复平台通知，或向客服提供任务 ID 和相关背景申请复核。

平台无法保证自动发现所有禁止内容。用户仍须遵守本 AUP，并主动举报可疑内容。被拦截的提示词不能替代紧急服务或执法机构的帮助。
